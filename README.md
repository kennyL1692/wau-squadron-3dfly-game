# Wau Squadron

A fast arcade space shooter. Fly a starfighter shaped like a Malaysian wau kite, clear the Haze from Paddy Rings, and beat the Giant Haze Locust.

**Play:** https://kennyl1692.github.io/wau-squadron/

## Controls

| | Laptop | Phone |
|---|---|---|
| Fly | Arrow keys / WASD | Drag |
| Shoot | Hold Space | Automatic while dragging |
| Spin (blocks bullets) | Shift | SPIN button |
| Boost | Hold E | Hold BOOST |

Built with three.js. Original game: no characters, art or music from existing games.
